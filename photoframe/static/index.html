      How to wire them

      Presence sensor

      A radar sensor (like the Waveshare 24 GHz mmWave) turns the screen on when someone's in the room, and off a while after they've left. It senses people even when they're sitting still.

      How to wire it

      Three wires: VCC → pin 17 (3.3 V), GND → pin 14, OT2 → pin 15 (GPIO 22). Use the 3.3 V pin only: these sensors can be damaged by 5 V. The sensor works through thin plastic or wood, so it can hide inside the frame, facing the room.

          Synced folders
          
                Link a folder from OneDrive, Google Drive, Dropbox or a NAS on your home network, and the frame
            keeps an album in step with it: add photos to the folder and they appear on the frame; take them out and they go.
            The frame only reads from these places and never changes them.
                
          
                Folder sync needs rclone on the frame. Re-run install.sh over SSH.
                
          
                This frame's rclone () is too old to download from OneDrive.
            Install the latest frame update (Maintenance tab), or see the README for a one-line fix.
