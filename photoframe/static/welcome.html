Anyone at home can use the frame's page for photos and the slideshow. The admin password protects the rest: software updates, backups, Wi-Fi, synced folders, SSH and resetting the frame.

Logging in to the Pi

Not needed to use the frame. An SSH login lets you (or someone helping you) work on the Pi from a computer. Without one, SSH stays switched off.
